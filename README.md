# idc
Investment Decision Calculator
----------------------------------------------
## Introduction

Investment Decision Calculator is a csharp based console application that calculates,

1. Payback Period.
2. Accounting Rate of Return.
3. Internal Rate of Return.
4. Profitability Index.
5. Net Present Value.
-----------------------------------------------------

## Installation

Go to the [Releases page](https://github.com/bsv1n4y/idc/releases), and download the latest version matching your operating system.

for example, Linux users should download **idc-linux-x64** and for Windows **idc-windows-x64.exe**.

-----------------------------------------------------------

## Usage

### On Linux

After downloading the binary package, go to the directory where you have downloaded the file and run this,

To make the binary executable

```bash
chmod +x idc-linux-x64
```
Then run the binary

```bash
./idc-linux-x64
```

### On Windows

Simply double-click the exe file to run the binary in the windows terminal
